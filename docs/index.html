Developer & AI Agent Integration

Plug into your CI/CD workflow or pair-program directly with AI assistants via Model Context Protocol.

.github/workflows/auto-arch.yml GitHub Actions 
name: Architecture Diagram
on:
  pull_request:
    paths: ['**/*.tf', '**/*.bicep', '**/template.yaml']

jobs:
  diagram:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: suryakumaran2611/auto-arch-diagram@v1
        with:
          image_formats: 'png,svg,drawio,html'
          direction: 'AUTO'
claude_desktop_config.json / mcp.json MCP Server (AI Pair Programming) 
{
  "mcpServers": {
    "auto-arch-diagram": {
      "command": "python3",
      "args": ["/path/to/auto-arch-diagram/tools/mcp_server.py"]
    }
  }
}

# • list_resources(files)
# • explain_graph(files)
# • generate_diagram(files, formats=['drawio', 'html'])
